# Niloofar Divandari Portfolio

A bilingual Persian/English portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Customize the portfolio
- Replace the three project placeholders in `index.html` with real project media and descriptions.
- Add image files to `assets/images/` and video files to `assets/videos/`.
- The project cards intentionally contain placeholders, not invented portfolio work.
- Skill levels are written descriptively. No estimated percentage scores are used.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder to the repository root, not the ZIP file.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub will provide the published site URL.

The site uses relative asset paths and is prepared for GitHub Pages project-site publishing.
